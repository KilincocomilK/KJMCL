# KJMCL 0.7.5

- 启动时自动检查 GitHub 上的最新正式版。发现更新后，可以从右上角通知打开对应的发布页。
- 修复国内镜像缺少游戏日志配置时安装失败的问题。镜像返回 404 或 410 后，启动器会从 Mojang 获取文件并校验。
- 资源管理支持从 RedenMC 搜索、预览和下载投影。模组的本地与在线搜索分开，支持中英文混合搜索，在线结果可直达发布页。
- 世界编辑支持加选与减选区块，删除前会再次确认。大地图拖动更流畅，备份世界时可选择导出位置。
- 统一像素字体与控件样式，侧栏功能入口可拖动排序，开始游戏、设置和账户管理固定。

## Windows x64 下载

`KJMCL-Setup-0.7.5.exe` 为安装版，`KJMCL-0.7.5.exe` 为便携版。两个文件均未签名，可使用随附的 `SHA256SUMS.txt` 核对下载内容。
