## 独立皮肤编辑器

- **2D / 3D 同步绘画**：经典与纤细模型、旧版 64×32 导入、64 / 128 / 256 工程、六向视图、部位和内外层控制。
- **像素工具**：画笔、橡皮、临时吸管、单面及跨模型边填充、替色、人体 / 面内镜像、形状、渐变、噪点、提亮压暗、克隆和雕刻。
- **图层与选区**：16 个编辑层、多种混合模式、锁定透明度、批量操作、选框 / 套索 / 魔棒、变换、撤销重做及历史定位。
- **颜色与素材**：HEX / RGB / HSL、透明度、命名调色板和文件导入导出；4 张可缩放平移及吸色的参考图；8 个可保存的 RGBA 印章。
- **组合与预览**：供体皮肤模型选择、部位混搭、自定义姿势、背景、前后对照、分辨率转换预览及游戏透明度检查。
- **作品管理**：版本化工程保存全部图层与工作区素材，自动草稿、损坏原件保留、备份恢复与最近 20 个作品版本。
- **独立输出**：PNG、64×64 / 旧版皮肤、可编辑工程、截图和 GIF；账户皮肤可导入新工程或图层，应用前选择账户并确认。

工具支持快捷键重绑和搜索。页面沿用中文、黑橙、直角布局，高级设置收进折叠面板。详见 [55 项实现与证据](../SKIN-EDITOR-IMPLEMENTATION.md) 和 [官方 / 社区调研](../SKIN-EDITOR-RESEARCH.md)。

## 升级与数据

启动器状态升级为 **schema v7**。从 0.7.2 的 v6 升级时保留 `state.json.v6.bak`；账户、实例、外部游戏文件夹、收藏、背景及原选中项继续保留。

皮肤工程独立使用 `schemaVersion: 1`，保存在受管 `skin-editor/` 目录并参与数据迁移。草稿在提交修改后保存，退出和重启等待保存队列。损坏草稿另存原件，恢复不会静默替换有效备份。导出拒绝覆盖已有文件。
