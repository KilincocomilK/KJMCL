# KJMCL 0.7.2

2026-11-13 · Windows x64 开发版

## 更新

- 左侧导航和主面板独立悬浮，采用黑橙直角毛玻璃界面，保持与背景的区分度。
- 首页聚焦实例选择和启动操作，增加留白，移除重复实例卡片、内存统计及“就绪”“JAVA EDITION”等冗余文字。
- “启动器设置 → 外观”支持 PNG / JPEG 本地背景，提供暗度、模糊及恢复默认。图片经主进程校验后保存受管副本，源文件删除或移动不影响使用。
- 页面和弹窗采用统一下拉菜单，支持键盘选择、输入匹配、Escape 关闭与视口内定位。
- 调整控件间距、操作区和小窗口布局，修复紧凑窗口下的存档页溢出。

## 升级与数据

状态升级为 schema v6，保留原账户、实例、外部游戏文件夹、选中项和原始状态备份；从 v5 升级时备份为 `state.json.v5.bak`。背景副本参与受管数据迁移。请勿用旧版本直接打开已升级的数据。

## 发行文件

- `KJMCL Setup 0.7.2.exe`：Windows x64 安装版。
- `KJMCL 0.7.2.exe`：Windows x64 便携版，数据默认位于 EXE 旁的 `KJMCL-data/`。
- `KJMCL Setup 0.7.2.exe.blockmap`：安装包分块校验信息。
- `SHA256SUMS.txt`：发行文件 SHA-256 校验清单。

## 验证与限制

本轮源码已通过类型检查、127 项单元测试、8 组 Windows Electron 桌面回归及构建。外观专项验证背景导入、源文件独立性、重启持久化、恢复默认、下拉框键盘和 960×650 布局；测试使用隔离数据和 JVM 测试类。

Windows x64 安装版与便携版使用匹配的 Electron 45.3.0 在 Windows 本机构建；打包后的应用通过全部 8 组桌面回归，实际便携 EXE 通过隔离数据迁移、重启及重新加载检查，包内及 PE 版本均核对为 0.7.2。

Windows 产物未签名。未完成真实 Minecraft、在线账户、下载源、Windows 系统级安装卸载或 macOS/Linux 实机验收。详细结果见 [验证记录](https://github.com/KilincocomilK/KJMCL/blob/v0.7.2/docs/VALIDATION.md)。
