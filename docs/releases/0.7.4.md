# KJMCL 0.7.4

Windows x64 本地发行包，2026-11-24。

## 本版内容

- 侧栏增加 AI 助手。可连接兼容在线或本地模型，诊断指定实例，预览、应用和撤销启动器及游戏配置。外部 Agent 可通过本机 MCP 服务读取信息并提交修改。[AI 助手使用指南](../AI-ASSISTANT.md)
- 工具箱包含种子地图和投影工坊。资源管理可直接打开投影，查看原版模型、材料和编辑记录。[种子地图](../SEED-MAP-IMPLEMENTATION.md) · [投影工坊](../PROJECTION-WORKSHOP.md)
- 侧栏提供启动器信息、下载与活动通知，集中查看任务进度和版本更新。

## 验证

Windows x64、Electron 45.3.0、JDK 21.0.7。类型检查、377 项单元测试、生产构建和完整 14 组桌面回归通过。打包后的助手通过模型管理、配置确认与撤销、重启恢复和本机 MCP 管理测试。模型回复来自回环 HTTP 测试服务。另在临时目录运行了实际便携 EXE，验证旁置数据、迁移、外壳重启及界面重新加载。

已核对安装版、便携版和包内版本，验证主进程、preload、助手页面资源及三个原生核心的摘要，并逐文件复核 SHA-256。两个 EXE 的 Windows 签名状态均为 `NotSigned`。真实云模型、第三方 Agent 和其他操作系统留待单独验收。
