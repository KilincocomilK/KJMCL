# KJMCL 0.7.6

- 首次打开时，新玩家可以跟随欢迎页创建游戏文件夹、添加账户并配置 AI 助手。每步都可以跳过，中途退出后会从上次的位置继续。
- 已有游戏的玩家可以自动查找官方启动器、HMCL、PCL2 和独立的 `.minecraft` 文件夹，也可以手动选择。预览版本和路径后，可沿用原目录，或复制版本、世界、模组、截图和游戏设置。账户需重新登录。升级用户可从「启动器设置 → 游戏目录与迁移」导入。
- Java 引导优先显示本机已安装的可用版本，并列出对应的 Minecraft 版本。按需安装后会启用自动匹配，设置新实例的默认内存。
- 账户页新增 LittleSkin 和 KJMC 认证预设，也支持自定义地址。Microsoft 应用客户端 ID 可在「账户管理 → Microsoft 账户」中设置。
- 安装游戏或启动从其他启动器导入的旧版本时，KJMCL 会优先复用校验通过的本地日志配置。缺少文件时会尝试从 Mojang 补全。

## 选择下载文件

| 系统 | 下载与使用 |
| --- | --- |
| Windows x64 | 常规安装选择 `KJMCL-Setup-0.7.6.exe`，便携使用选择 `KJMCL-0.7.6.exe`。 |
| macOS | 选择与 Mac 芯片架构相符的 `.dmg`，打开后将 KJMCL 拖入「应用程序」。 |
| Ubuntu x64 | 选择 `.deb` 安装到系统，或为 `.AppImage` 添加执行权限后直接运行。 |
