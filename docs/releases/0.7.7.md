# KJMCL 0.7.7

- 启动器换上图标图鉴中的两款新图标。
- Microsoft 账户登录已内置 KJMCL 的应用 ID。在「账户管理」中获取设备码，到微软页面输入即可授权。已有自定义应用的账户可继续使用原配置。
- 安装整合包前可预览必需、可选和跳过的文件。安装中断后，从首页继续同一实例即可复用已校验的文件。导入支持 KubeJS、自定义配置和客户端覆盖文件。此前旧版留下的失败实例若没有原清单，需要重新导入整合包。
- 「检查模组更新」先列出变更和下载大小。确认后整批应用，失败会回滚，成功后也可以撤销。更新游戏版本、加载器或整合包时，可以创建独立副本试更。副本会优先复用与当前存档内容一致的备份。
- 首页分别显示 Java 已启动、游戏加载中和已进入世界。确认进入世界后才更新最近游玩时间。启动失败时可在首页查看原因，按需重新授权、补齐资源、撤销模组更新或打开诊断。

## 选择下载文件

| 系统 | 下载与使用 |
| --- | --- |
| Windows x64 | 安装版选择 `KJMCL-Setup-0.7.7.exe`，便携版选择 `KJMCL-0.7.7.exe`。 |
| macOS | 选择与 Mac 芯片架构相符的 `.dmg`，打开后将 KJMCL 拖入「应用程序」。 |
| Ubuntu x64 | 选择 `.deb` 安装到系统，或为 `.AppImage` 添加执行权限后直接运行。 |
