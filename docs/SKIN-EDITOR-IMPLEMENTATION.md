## 本轮实际执行的验证

最终全库检查：22 个测试文件、270 项测试通过，类型检查通过。源码浏览器测试还验证了模型解释 / 像素转换、分辨率预览取消 / 应用、批量图层单次撤销、Alt 临时吸管不改图、供体模型预览取消，以及未保存工程保护。宽屏与 960×650 截图已检查。没有执行构建打包；原生桌面与真实服务限制见 [验证记录](VALIDATION.md)。

关机保存补测最后执行：

```text
npx vitest run tests/skin-editor-storage.test.ts tests/skin-editor-features.test.ts
2 test files passed; 57 tests passed

npm run typecheck
passed
```

此前 9 个工作区素材测试通过。主任务已执行源码浏览器 UI smoke，并获得双视图精确 RGBA、参考图、印章、姿势、滤镜取消和动画捕帧证据。完整测试总数和最终复跑结果统一记入 `docs/VALIDATION.md`。

新增关机测试使用可控暂停的真实临时目录保存队列：`flush()` 会等待原有写入，也等待过程中加入的下一次写入。未修复的失败会报告；草稿重试成功后清除该目标的旧失败，不因另一个作品成功保存而误清除草稿失败。主进程停止其它服务后再做最后一次队列检查，重复退出事件不会跳过等待。

大图测试确实触发了旧 `decodePixels` 嵌套重复正则的 `Maximum call stack size exceeded`，现已替换为长度与简单字符校验；补测 2048×1024 RGBA 参考图、256×256 工程和非法 Base64。不是通过降低合法输入尺寸避开问题。

以上是源码审核阶段记录：当时按用户要求未运行 `npm run build`、打包命令或会隐含编译的 `npm run test:desktop`。用户现已授权 0.7.3 Windows 本地构建、验证和打包，不发布上传；本次原生回归与产物状态见 [0.7.3 发布说明](releases/0.7.3.md) 和 [验证记录](VALIDATION.md)。真实账户和真实 Minecraft 行为仍需相应环境验收；上述模拟上传不会被记为真实服务验证。

## 继续迭代时的审查重点

1. F11 临时吸管、F32 批量图层、F38 供体预览和模型选择、F43 账户新工程入口已补齐；后续应检验各入口的真实操作组合，而不是再次把 API 存在当作交互完成。
2. 磁盘导入异步返回必须检查工程身份，并基于最新工作区合并素材；不要以旧闭包覆盖刚改的姿势或色板。
3. 参数、素材和几何的新增能力必须在经典 / 纤细、内 / 外层、HD、选区、锁定层下交叉验证，不能只在空白 64×64 经典模型上通过。
4. 最终界面验收应补可重复的真实交互证据。仍不宣称穷尽所有第三方编辑器的功能，也不把等待视觉验收误写成已全部完成。
