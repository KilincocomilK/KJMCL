模组搜索结果另补充“选择版本”和收藏按钮，复用兼容版本安装流程。所有新文件读取、导出、账户排序与启动处理均在主进程；预加载只暴露命名接口，参数由共享 schema 校验。

## 启动与数据

- Quick Play 依据实际版本元数据的功能规则启用；不支持的版本不可新选快速目标，已保存但失效的目标会报错。不会为旧版本猜测或注入另一套参数。
- Java 仍以独立参数数组、`shell: false` 启动。世界名含空格时仍是一个参数；存档路径和 Quick Play 输出路径检查链接。
- 状态升级为 **v7**，升级前保留 `state.json.v6.bak`（更旧数据按原版本保留）。实例、账户、文件夹、背景、收藏和已有选中项保留。
- 克隆继承启动偏好；不复制存档时，克隆的单人世界目标回到主菜单。
- 日志界面仍保留最近 2000 条，暂停只冻结显示。完整导出是启动器解码后的持久化日志，可能包含多次启动，不是原始 stdout 字节；超过 64 MiB 会报错，不输出截断的“完整”文件。导出会脱敏，并拒绝覆盖已有目标。
