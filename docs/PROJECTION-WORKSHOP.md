# 投影工坊

入口为「工具箱 → 投影工坊」，与皮肤编辑器、种子地图并列。界面沿用中文黑橙直角风格，主要操作集中在视图工具栏及右侧「编辑 / 材料」。本轮更新源码与开发构建，不重新生成 0.7.3 安装包。

## 功能

- 导入 Litematic v6/v7、Sponge Schematic v2/v3、Minecraft 结构 NBT；支持拖入文件和作品库。
- Deepslate 原版模型与贴图预览，Three.js 显示与拾取；旋转 / 平移 / 缩放、适应视图、正交视角、网格、全屏和 Esc 退出。
- Y 层范围、单层查看、分层间距，便于观察建筑内部。
- 单选、追加选择、屏幕框选、坐标范围选择、相同材料、同一层和六邻接连通选择。
- 隐藏所选、只显示所选、全部显示，双点测距和坐标复制。
- 批量替换方块及方块状态、删除所选、顺逆时针旋转、X/Z 镜像、重命名。
- 撤销与重做，最多保留 20 次编辑历史；新分支清除旧重做链。
- 材料按实际方块状态计数，可筛选和查看组 / 余数，导出 CSV。
- 导出 Litematic、Schem、结构 NBT、当前视图 PNG；可安装到所选实例的 `schematics/`。
- 自动保存、作品库重开、真实关闭重启恢复；目录损坏时可明确选择恢复备份并归档原件。

原版 blockstates 与 models 决定楼梯、台阶、门、栅栏、玻璃板等几何及朝向；贴图保留像素、透明度和动画，玻璃 / 水与实体表面分别处理。水和熔岩读取 level，含水方块保留固体模型。切层、隐藏及展开层间距时重新计算可见面，选择高亮独立于原版材质。

模型按需烘焙和缓存，合并可见区块网格并剔除内部面。缓存最多 4,096 项 / 16,384 面，单次视图最多 300,000 面；复杂投影可按层查看，完整工程和导出不受视图预算影响。退出工具时释放图集与 GPU 资源。

模型生成复用 MIT [Deepslate](https://github.com/misode/deepslate) 0.27.3，原版资源从经过哈希校验的官方客户端提取，不随启动器分发。首次使用准备资源，后续读取缓存；失败可重试。界面显示资源版本，未找到的模型使用缺失纹理并计数。模组资源包导入、游戏实体渲染、逐群系光照不在本轮范围。Deepslate 的流水为分级水平面，随机模型取首项，UV lock 尚未实现；详见 [渲染研究](PROJECTION-RENDERER-RESEARCH.md)。

实体、计划刻、生物群系等附加数据的编辑和跨格式转换按原生核心可支持的范围执行；不能保留时返回错误，原件和已保存版本保持。

## 数据和原生核心

`shared/projection.ts` 定义类型与校验，命名 preload 连接 `electron/projection-features.ts`。`electron/core/projection-workshop.ts` 串行处理修订、作品库和导出；每次修改校验当前修订，避免旧视图覆盖新版本。文件、NBT、子进程均留在主进程或原生进程。

`shared/projection-assets.ts` 定义资源请求和返回结构，`electron/core/projection-assets.ts` 校验官方版本元数据及客户端 SHA-1，优先复用匹配的本地客户端。资源缓存位于 `projection-workshop/assets/`，可离线复用，损坏索引隔离后重新获取。模型父级、贴图及动画元数据按依赖读取；原版客户端本身不在渲染进程打开。

Rust 核心位于 `electron/native/projection/`，独立解析 NBT、压缩、调色板及体素打包，执行材料统计、选择和批量变换。Windows 使用本机 MSVC Rust target；产物由构建脚本写入 `dist-native/projection/`，启动前检查系统、架构和 SHA-256，不通过 shell 启动。

未编辑的同格式导出保留原始文件字节。普通替换 / 删除的同格式导出保留原分区和未知元数据；旋转 / 镜像或跨格式导出生成单一正尺寸分区，并将原始 NBT 留在附加档案中。带容器的同格式旋转 / 镜像同步方块实体坐标及方块朝向，保留物品 NBT 和计划刻。复杂游离实体、生物群系或特殊坐标 NBT 的变换，以及带附加数据的跨格式转换会明确拒绝，不静默丢弃。旧 MCEdit `.schematic` 不在本轮支持范围。

受管目录 `projection-workshop/` 使用独立 `schemaVersion: 1` 索引及工程文件，参与数据迁移和明确选择的卸载清理；主状态保持 v7。最多保存 32 个作品、每个 21 个历史快照；单个投影限制为 200 万体积格、25 万非空气方块，单轴不超过 2048。原生文件与解压结果有大小、深度和集合长度限制。导出使用相邻临时文件，成功后才落到目标，拒绝覆盖已有文件。

来源与格式核验见 [调研记录](PROJECTION-WORKSHOP-RESEARCH.md)。测试范围与结果见 [验证记录](VALIDATION.md)。没有复制美西螈或其他启动器的实现，本地 `SJMCL/` 未修改。
