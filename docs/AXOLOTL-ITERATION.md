日期：2026-11-12。参考范围为 [Axolotl 项目说明](https://github.com/Axolotl-Launcher/Axolotl)、[1.10.5 稳定版](https://github.com/Axolotl-Launcher/Axolotl/releases/tag/v1.10.5) 及 [1.11.0-beta.4 发布记录](https://github.com/Axolotl-Launcher/Axolotl/releases/tag/v1.11.0-beta.4)。仅参考公开功能与行为，未复制实现，也未修改排除目录 `SJMCL/`。

本轮完成内容发现、实例整理和维护诊断三组迭代，并做交叉回归。停止继续扩展的判断依据是：从寻找内容、选择版本、整理多个实例，到发现模组问题、管理存档、联机、导出排查证据和回收缓存，已有可操作的流程。此判断不代表已实现参考项目的全部功能或达到其成熟度。

## 使用说明

- **内容中心**：先选目标实例，再选择来源、类别、关键词和排序。结果按 Minecraft 版本筛选，模组还筛选加载器。打开“选择版本”查看文件名、大小、渠道和必需依赖数量，再安装。模组沿用依赖安装器，资源文件校验后添加，整合包进入原有独立实例导入流程。CurseForge 需要设置 API Key，并尊重作者的 API 下载许可。
- **收藏夹**：点击星标收藏，按类别或分组筛选，在卡片填写分组并离开输入框保存。已收藏内容可离线浏览、改组和移除；首次收藏会读取项目的真实元数据。收藏保存到本机，不提供云同步。
- **游戏实例**：搜索名称、版本、加载器、标签或备注。星标置顶；标签按钮打开分组、标签、备注编辑。列表显示最近游玩和累计时长，沿用已有真实启动记录，不填充示例统计。
- **模组中心 → 检查与批量操作**：读取当前实例 JAR，选择全部筛选结果或勾选文件，预览启停文件名变更，再执行。改变的是 `.disabled` 后缀，不修改 JAR 内容。游戏或实例任务运行时禁止操作。
- **崩溃报告**：浏览实例 `crash-reports/crash-*.txt`、根目录 `hs_err_pid*.log`、`logs/latest.log` / `debug.log`。支持关键词和异常行筛选。导出包只含所选报告、基础版本信息和规则诊断，不自动上传。
- **磁盘管理**：按需扫描目录逻辑体积；不会跟随链接。清理只处理活动数据目录 `cache/` 内超过 24 小时且经过本次预览的普通文件，执行时再次核对身份和修改时间；近期或已经改变的文件保留。

## 安全与持久化

命名 preload、共享类型、Zod 输入验证和主进程处理同步扩展；网络、凭据、文件读取与写入全部保留在 Electron 主进程。新增页面分散在 `src/pages/`，领域服务在 `electron/core/`。

`state.json` 从 v1 / v2 / v3 迁移至 **v4**。新增内容收藏列表和实例整理字段，保留账户、目录、设置、游戏时长，迁移前保存对应 `state.json.vN.bak`。未知版本或损坏数据会报错，原数据不被空状态替换；数据目录中断恢复同步接受 v4。不要直接用 0.5 或更早版本打开升级后的状态。

模组批量操作有 10 分钟的一次性预览令牌。执行前检查全部源文件 SHA-256 和目标冲突，普通 I/O 失败时回退已完成的重命名；它不提供断电事务日志，强制结束时可能仅部分文件改变启用状态，JAR 内容仍保留。再次检查并批量启停可整理状态。

内容安装不覆盖同名非托管文件。Modrinth 使用 SHA-512，CurseForge 使用其提供的 SHA-1；文件大小、项目身份、游戏版本也会检查。指定模组版本增加了项目归属核对，防止装入错误项目的文件。

诊断读取前，收集主进程内当前令牌及系统加密凭据，用于遮蔽已知秘密；凭据不能解密时停止导出。另遮蔽常见 token、password、API key、邮箱、本机目录及 Windows 短路径别名。规则无法保证识别模组任意自定义日志中的全部私人信息，分享前仍可在本机查看。单份报告最多读取 4 MiB，普通日志读尾部，崩溃/JVM 报告读头部，界面明确标识截断。

ZIP 导出先写同目录临时文件，完成后以不覆盖方式发布；失败或取消会清除自身临时目录。同一机制用于存档 ZIP 导出，修复此前取消可能留下不完整导出文件的问题。不会覆盖已有文件或源报告。

缓存清理不触及实例、存档、完整备份、凭据、共享运行库或托管 Java。扫描采用逻辑文件长度，硬链接可能重复计数；这不是实际磁盘占用或卸载估算。扫描跳过的路径会显示警告，清理不自动删除未知文件夹。

## 仍未覆盖的能力

- 尚无资源包 / 光影托管版本记录与自动替换更新；同一项目的新文件可另行安装，旧文件在资源管理中处理。有必需依赖的非模组资源会说明限制并拒绝自动安装，避免遗漏依赖。模组仍使用原有依赖解析与更新流程。
- 内容版本弹窗显示所选主文件及依赖数量，未实现 Axolotl 式完整依赖图和整合包差异升级审核。在线整合包通过现有导入器创建默认目录实例，未提供该入口的目录自选。
- 模组检查不会完整模拟加载器求解。Fabric / Quilt 顶层依赖仅用于提示，内嵌 JAR 和复杂版本约束需加载器确认；Forge / NeoForge 只读取明确的模组 ID，不将简单 TOML 文本推断成完整依赖模型。
- 没有 Studio 图像/皮肤编辑器、旗帜设计器、世界种子预测器、完整投影编辑、任意文本文件编辑器、独立服务器托管或 AI / MCP 控制服务。
- 没有云收藏同步、自动升级签名渠道、下载断点续传、多连接分段下载或完整弱网任务恢复。发布基础设施和平台签名仍需项目自己的配置。

新增网络实现按 [Modrinth API](https://docs.modrinth.com/api/operations/getversions/) 与 [CurseForge API](https://docs.curseforge.com/rest-api/) 的公开数据接口设计，复用现有 HTTPS、代理、下载校验及任务系统。
