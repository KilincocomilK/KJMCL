# 工具箱与种子地图

本轮在现有 0.7.3 源码上继续开发。侧栏「工具箱」统一进入皮肤编辑器和种子地图；账户页的编辑皮肤、存档页的种子地图仍可直接进入对应工具。切换工具保留当前编辑内容。本轮不更新既有安装包。

## 已实现

| 功能 | 行为 |
| --- | --- |
| 种子输入 | 正负 64 位整数保持字符串精度；文本按 Java UTF-16 hashCode 解析；支持随机种子和复制 |
| 版本 | 原生核心提供 33 个明确 Java 版本，从 1.0.0 至 26.3；未知版本不会被静默替换 |
| 三维度 | 主世界、下界、末地；结构与群系列表跟随维度 |
| 世界选项 | 群系采样高度、巨型群系；从存档读取名称、种子、版本、出生点和生成预设 |
| 地图操作 | 鼠标拖动、光标位置缩放、缩放按钮、方向键和加减快捷键；比例尺与北向 |
| 全屏 | 原生窗口全屏开关、Esc 返回；面板可收起，大视口完整覆盖 |
| 坐标 | X/Z 跳转、原点、预测出生点、悬停方块和区块坐标、复制坐标与传送指令 |
| 下界换算 | 主世界与下界坐标换算并切换维度 |
| 群系 | 真实群系 ID 与颜色、中文图例、过滤、高亮、按光标精确采样 |
| 结构 | 29 类目录（含出生点、要塞、史莱姆区块）；按版本和维度筛选、逐项开关、全选与隐藏 |
| 结构定位 | 从视图中心按半径寻找，结果距离排序，可跳转和取消；不编造结构 Y 坐标 |
| 群系定位 | 按高度和半径采样查找，显示实际采样间隔；小群系可能处于采样点之间 |
| 网格与史莱姆 | 负坐标正确对齐；独立 Java RNG 判定区块，支持地图叠层 |
| 标记 | 名称、坐标、维度、颜色、备注、编辑、删除和跳转；每张地图至多 500 个 |
| 收藏 | 保存地图选项、视图与标记，最多 64 张；切换有未收藏标记的地图时可先保存 |
| 存档入口 | 工具内选择实例与世界，或选择外部 level.dat；存档管理页也可直接打开 |
| 工程 | `.kjmap` 与标记 JSON 导入导出，校验版本、种子、坐标和重复编号 |
| 图片 | 导出已生成的当前地图、比例尺和标记为 PNG，主进程重新解码校验 |
| 自动保存 | 工作区与收藏独立版本化；写入串行合并，退出和重启等待落盘 |
| 恢复 | 保存前保留备份，损坏原件归档；恢复操作不静默清空地图 |

界面沿用中文、黑橙、直角；结构、查找、图例与标记收进侧面折叠栏。详情只保留「近似」和实际采样间隔等影响使用的短提示。

## 实现与性能

`src/pages/Toolbox.tsx` 提供统一入口，`src/pages/SeedMap.tsx` 管理地图工作区，`src/seed-map/` 负责 Canvas 和坐标计算。Renderer 通过命名 preload 调用主进程，不直接访问磁盘、网络或子进程。

`electron/core/seed-map.ts` 验证原生文件清单、平台架构与 SHA-256，使用无 shell 的独立进程。最多同时运行两个原生任务，支持排队取消、请求失效与瓦片缓存。地图使用 128×128 瓦片，采样尺度随缩放和视口调整；取消或切换后的旧结果不能覆盖当前地图。

原生核心位于 `electron/native/seed-map/`：Rust 处理协议、边界和查询，实际生成调用 MIT 的 Cubiomes C 算法库，固定 xpple fork 提交 `b99f6e472018cab903a096697117aab9d9170a19`。没有复制其他启动器或 GPL Cubiomes Viewer 的实现。来源、许可、算法参数表和参考坐标见 [调研记录](SEED-MAP-RESEARCH.md) 与 [原生来源说明](../electron/native/seed-map/vendor/UPSTREAM.md)。

Windows x64 需要 MSYS2 UCRT64 GCC / binutils 和 Rust `x86_64-pc-windows-gnu`；构建检查外部 DLL 依赖，并在只有 Windows 系统目录的 PATH 中启动测试。玩家无需安装 Rust 或 GCC。原生运行库声明并入 `THIRD_PARTY_NOTICES.txt`。既有 Rust 存档核心继续使用 MSVC。

## 数据与边界

`seed-map/workspace.json` 使用独立 `schemaVersion: 1`；主状态仍为 v7。地图目录参与受管数据迁移和明确选择的卸载清理。导入只读取存档，地图操作不改写 Minecraft 世界。文件导出不覆盖现有文件。

地图预测 Java 默认 / 巨型群系生成。结构经过算法库可用的群系与地形检查，仍不是完整方块世界生成；出生点、要塞和结构详情保留近似标识。1.0 在算法库中属于实验支持。26.x 参数表及固定样本已核验，但未逐块与真实游戏全面对照。超平坦、放大化和自定义世界使用默认预测时有短提示；模组与数据包改变的世界生成、既有区块的历史版本不在此模型内。没有提供 Bedrock、矿脉、战利品或完整三维洞穴重建。

最新测试结果和实际验证范围见 [VALIDATION.md](VALIDATION.md)。截图与合成存档仅存在于临时测试目录，不进入玩家数据或发行文件。
